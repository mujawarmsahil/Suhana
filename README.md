# Suhana Firoj Attar: Architecture Portfolio
Static site: index.html plus the images/ folder (all photos, renders and drawings used). No build step.

## Git
git init && git add . && git commit -m "Add architecture portfolio"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main

## Vercel
Import the repo at vercel.com/new. Framework preset: Other. Leave build command and output directory empty.
Or from the folder: npx vercel --prod
